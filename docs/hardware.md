# 硬件规格

主板：微雪 ESP32-S3 1.75" AMOLED 圆形触摸开发板（铝合金外壳 + 挂绳，胸前佩戴）。

## 固件支持矩阵

固件按 board 硬件抽象层组织（ADR-076）：业务代码只经 `Board::instance()` 拿板级
能力，新增板子 = `main/boards/<board>/` 新目录 + config.json 声明构建变体，共享代码不动。

| 板子 | 目录 | 选板宏 | config.json 变体名 | 激活方式 | 状态 |
|---|---|---|---|---|---|
| 微雪 ESP32-S3-Touch-AMOLED-1.75C | `main/boards/waveshare-s3-amoled-1_75c/` | `GAGA_BOARD_WAVESHARE_1_75C` | `waveshare-s3-amoled-1_75c` | 右下点按录音 / 右上单击回主页+长按 talk / IMU 手势（摇一摇）/ 语音唤醒 | ✅ 当前唯一在册（本机） |

变体参数（pio board / flash 容量 / 分区表 / sdkconfig 体质参数）的权威在板目录
`config.json`，构建入口 `esp32-idf/scripts/build.py`（ADR-077）；物理键→动作的
映射收在板层 `board_input.cpp`（ADR-078），不同板子激活方式不同。

| 部件 | 型号/规格 | 用途 |
|---|---|---|
| 主控 | ESP32-S3R8 双核 240MHz，8MB PSRAM，外接 Flash 实测 32MB（Wiki 写 16MB 过时） | 向量指令集、BLE 5.0、原生 USB |
| 屏幕 | 1.75" AMOLED 466×466，CO5300（QSPI） | 黑像素零功耗，支持息屏显示 |
| 触摸 | CST9217（I2C 共享总线） | |

| 收音 | ES7210 双麦 ADC（硬件 AEC 能力） | 麦克风 → ESP32 |
| 放音 | ES8311 codec（只用 DA 半边）+ NS4150B 2.4W 功放（使能脚 GPIO46） | ESP32 → 喇叭 |

| 接口 | Type-C 原生 USB（macOS 免驱，/dev/cu.usbmodem*） | 烧录 + 串口控制台 |
| 外壳 | 铝合金 + 挂绳 | 胸前佩戴 |

## 按键分工（2026-09-26 定稿，ADR-016/045；1.75C 专属，实现 = 板层 board_input.cpp）

| 按键 | 动作 | 功能 |
|---|---|---|
| 右上 | 按下 | 亮屏（按下沿即亮） |
| 右上 | 单击 | 亮屏 + 回主页；无操作 10 秒自动息屏 |
| 右上 | 长按 | 进入/结束实时对话模式 |
| 右下 | 按一下 | 开始录音；录制 <300ms 静默丢弃（防误触） |
| 右下 | 再按一下 | 结束并发送；录音期间手可以离开（挂脖骑车场景） |

摇一摇与右下键同权：任一都能开始/结束录音。

## 到手第一件事

```bash
pip3 install esptool
esptool.py --port /dev/cu.usbmodemXXXX read_flash 0x0 0x2000000 factory_backup.bin
```

备份原厂 32MB 固件（0x2000000 = 32MB，别抄 8MB 教程）。
⚠️ 2026-09-22 备份的那份经用户确认是前手刷过的未知系统，已删除；如需原厂镜像向微雪官方索取。

## 功耗（估算档，实测归档在 power-log.md）

| 状态 | 估算电流 | 600mAh 电池 |
|---|---|---|
| 深度休眠 | ~0.1mA | 按周计 |
| 息屏待机 | ~10~25mA | 1~2 天 |
| 亮屏使用 | ~60~150mA | 半天 |
| 语音通话（息屏） | ~100~250mA | 3~5 小时 |

音频前端按需上电：只有录音/对话时才给麦克风和喇叭通电（ADR-027），待机功耗回到上表水平。
电老虎是音频 + 屏幕，不是通信（BLE 转发仅 10~30mA）。

## 骑行风噪四层防线

1. 凑近嘴边说话（距离平方律，最强手段）
2. 麦克风孔贴防风棉（砍 10~20dB 低频风噪）
3. ESP-SR AFE 噪声抑制（NS 模块；AEC 仅实时对话上岗）
4. 服务端 ASR 鲁棒性兜底

## 引脚定义

权威来源 = 固件 `main/boards/waveshare-s3-amoled-1_75c/board_config.h`（GAGA_* 宏
re-export 微雪官方 BSP + 对照 `reference/` 原理图，不许猜；板级电气约束——REG0E
下电序列、PA 高有效、1.75 旧板 MCLK=42 差异——写在该文件头注释里）。
本机是 **1.75C** 版，与 1.75 的关键差异 = 音频 MCLK 在 GPIO16（决定性实验定案，详见 ADR-018 / ../.agents/bug-analysis-0923.md Bug1）。

| 功能 | 引脚 |
|---|---|
| 屏幕 CO5300（QSPI） | CS=12, SCLK=38, SDIO0~3=4/5/6/7, RST=39 |
| 共享 I2C 总线 | SDA=15, SCL=14（触摸/IMU/PMU/RTC/IO 扩展共线） |
| 触摸 CST9217 | INT=11, RST=40 |
| I2S 音频 | BCLK=9, WS=45, DOUT=8（→功放→喇叭）, DIN=10（麦克风→）, **MCLK=16**（1.75C 实锤）, PA 使能=46 |
| IMU QMI8658C | I2C 0x6B；INT1→GPIO21（RTC IO，可深睡唤醒，固件当前轮询未接中断） |
| BOOT 键 | GPIO0 = 物理**右下**键 |
| PWR 键 | 非 GPIO，接 AXP2101 PKEY = 物理**右上**键 |
| TF 卡（备用） | CLK=2, CMD=1, DATA=3, CS=41 |
